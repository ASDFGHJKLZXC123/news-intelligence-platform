GNU Unifont -- bundled font asset for the Stage 6 daily-brief PDF export
========================================================================

File            : unifont-14.0.04.ttf
Upstream source : https://ftp.gnu.org/gnu/unifont/unifont-14.0.04/unifont-14.0.04.ttf
Upstream version: 14.0.04
SHA-256         : 211d1ddddc566511db254c746d83df77b4a1b9b2549cdffe0a3e901e46eefea8

The file is the unmodified upstream release, bundled verbatim so that the PDF exporter
(services/reports/_pdf.py) can embed a subset of it with no network access and no dependence
on any system-installed font. It is read from disk only.
